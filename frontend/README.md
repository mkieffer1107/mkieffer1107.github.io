# Board Game AI Challenge

A web-based game application featuring Tic-Tac-Toe, Connect Four, and Othello with an AI opponent powered by Monte Carlo Tree Search (MCTS).

## Features

- Three classic board games in one application
- AI opponent with adjustable difficulty
- Responsive design for desktop and mobile
- Sophisticated MCTS algorithm with heuristic evaluation

## Live Demo

Visit the live demo at: [https://yourusername.github.io/board-game-ai/](https://yourusername.github.io/board-game-ai/)

## How to Play

1. Select a game from the game selector
2. Choose AI settings (time-based or simulation-based)
3. Make your move when it's your turn
4. Try to beat the AI!

## Local Development

\`\`\`bash
# Clone the repository
git clone https://github.com/yourusername/board-game-ai.git
cd board-game-ai

# Install dependencies
npm install

# Run the development server
npm run dev
\`\`\`

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.
